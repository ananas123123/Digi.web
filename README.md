# Digi Web

Public Digi installer website.

## Current scope
- Home
- Installer download
- Release history
- Requirements
- Installer verification
- Help/source links
- Live GitHub release lookup

Installer information is read from the Digi GitHub Releases API. The current Digi repository has no published release/installer asset yet, so the site reports that state rather than pretending an installer exists.

## Development
npm install
npm run dev
npm run build
